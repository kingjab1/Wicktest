# Sound library

Sounds for the editor's Sound Effects panel. Everything here can be shared freely:

- Every category except **Game Blips** was generated from scratch by `synth.py` for this site and is released under CC0 (public domain).
- **Game Blips** are the sounds that ship with the Wick Editor. Each is CC0 from Freesound.org; the credit and link for each one are in `catalog.json`.

Don't add sounds here unless their license allows redistribution (CC0 or similar). A sound pack you bought for your own use usually doesn't.

To add a sound: put the `.mp3` in a category folder and add an entry to `catalog.json` (`category`, `name`, `file`, `seconds`, `credit`, `license`).
